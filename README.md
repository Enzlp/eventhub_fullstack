# EVENTHUB
EventHub es una plataforma Full Stack para la creación, gestión y descubrimiento de eventos. Permite a los organizadores publicar eventos y administrar sus inscripciones, mientras que los participantes pueden explorar eventos disponibles, reservar cupos y gestionar sus reservas. El proyecto busca demostrar conocimientos de desarrollo frontend y backend, integración de APIs REST y gestión de bases de datos.
